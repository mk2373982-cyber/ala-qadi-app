# تطبيق "على قدي" (Ala Qaddi) 💰
### تطبيق إدارة مالية شخصية محلي وخاص (Local-First PWA)

تطبيق مصمم للمستخدم العربي لإدارة المصاريف والديون والجمعيات والمدخرات. الحساب والبيانات المالية محلية على الجهاز؛ لا توجد مزامنة بين الأجهزة أو إدارة اشتراكات في هذا الإصدار.

---

## 🌟 أبرز المميزات:
1. **الخصوصية والعمل أوفلاين (Local-First)**: كافة البيانات المالية مخزنة محلياً على جهاز المستخدم (IndexedDB) وتعمل 100% بدون اتصال بالإنترنت.
2. **حساب محلي**: إنشاء حساب على الجهاز للدخول إلى التطبيق. الحساب لا يُستعاد تلقائياً على جهاز آخر.
3. **أقسام متكاملة**:
   - 🏠 **الرئيسية**: رصيد المحفظة، المتبقي من الراتب، شريط تقدم الميزانية الذكي.
   - 💳 **سجل المعاملات**: تصنيفات مصرية جاهزة (مصاريف بيت، بنزين، علاج، فواتير) وتصدير Excel (CSV).
   - 🤝 **قسم "ليّا وعليّا"**: سلف مستحقة عند الغير + ديون والتزامات مع سداد جزئي.
   - 🪙 **الجمعيات والذهب**: حساب الجمعيات الشهرية وموعد القبض، ومحفظة الذهب (عيار 21 و 24) والعملات.
   - 📊 **الميزانية والتقارير**: نسب المصروفات وطباعة تقرير شهري PDF.
   - ⚙️ **النسخ والاحتياطي**: حفظ نسخة مشفرة من البيانات ونقلها لأي جهاز آخر بسهولة.

---

## 🚀 التشغيل محلياً:

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# أو بناء الإنتاج والتشغيل
npm run build
npm start
```

- رابط التطبيق للمستخدمين بعد النشر: رابط Vercel الخاص بالمشروع.
- لتجربته محلياً: `npm run dev` ثم افتح `http://localhost:3000`.
- لتثبيته على الهاتف: افتح الرابط عبر المتصفح واختر «إضافة إلى الشاشة الرئيسية».

## النشر

ارفع هذا المجلد إلى مستودع GitHub مستقل ثم استورده في Vercel كـ Next.js. بيانات المستخدم المالية والحساب المحلي تُحفظ في مساحة المتصفح على كل جهاز ولا تُرسل للسيرفر. مسح بيانات المتصفح أو استخدام جهاز آخر يتطلب إنشاء حساب محلي جديد؛ استخدم النسخة الاحتياطية لنقل البيانات يدوياً.
