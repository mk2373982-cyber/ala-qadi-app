# تطبيق "على قدي" (Ala Qaddi) 💰

### تطبيق إدارة مالية شخصية محلي وخاص (Local-First PWA)

تطبيق مصمم خصيصاً للمستخدم العربي والمصري لإدارة المصاريف، الديون ("ليّا وعليّا")، الجمعيات الشهرية، ومدخرات الذهب والأصول بكل بساطة وهدوء، مع لوحة تحكم وتراخيص مخصصة للبيع المباشر.

---

## 🌟 أبرز المميزات:

1. **الخصوصية والعمل دون اتصال (Local-First)**: سجلات المعاملات والميزانيات والديون محفوظة محلياً على جهاز المستخدم (IndexedDB)، ويمكن استخدامها دون اتصال بعد تسجيل الدخول وتحميل التطبيق مرة واحدة على الأقل. إنشاء الحساب وتسجيل الدخول أول مرة والتحقق من الاشتراك وإدارته تحتاج إلى الإنترنت.
2. **الاشتراكات ولوحة المسؤول (`/admin`)**: مراجعة الدفع وإدارته، تفعيل الاشتراك أو إيقاف الحساب، وتعديل بيانات التحويل الظاهرة للمستخدم.
3. **تجربة مجانية عند التسجيل**: لا يوجد استخدام بدون حساب؛ كل حساب جديد يبدأ استخداماً كاملاً مجانياً لمدة 30 يوماً من تاريخ التسجيل (عرض الإطلاق)، ويحتاج بعدها إلى تجديد الاشتراك. سجلات العميل المالية تبقى محلية على جهازه طوال الفترة.
4. **أقسام متكاملة**:
   - 🏠 **الرئيسية**: رصيد المحفظة، المتبقي من الراتب، شريط تقدم الميزانية الذكي.
   - 💳 **سجل المعاملات**: تصنيفات مصرية جاهزة (مصاريف بيت، بنزين، علاج، فواتير) وتصدير Excel (CSV).
   - 🤝 **قسم "ليّا وعليّا"**: سلف مستحقة عند الغير + ديون والتزامات مع سداد جزئي.
   - 🪙 **الجمعيات والذهب**: حساب الجمعيات الشهرية وموعد القبض، ومحفظة الذهب (عيار 21 و 24) والعملات.
   - 📊 **الميزانية والتقارير**: نسب المصروفات وطباعة تقرير شهري PDF.
   - ⚙️ **النسخ والاحتياطي**: حفظ نسخة من البيانات في مساحة التطبيق الخاصة بحساب Google Drive ونقلها لأي جهاز آخر.

---

## 🚀 التشغيل محلياً:

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# فحص الكود (ESLint flat config) والأنواع والاختبارات
npm run lint
npx tsc --noEmit
npm test

# أو بناء الإنتاج والتشغيل
npm run build
npm start
```

- رابط التطبيق للمستخدمين: `http://localhost:3000`
- لوحة تحكم المسؤول: `http://localhost:3000/admin` (تحتاج إلى إعداد `ADMIN_PASSWORD` في متغيرات البيئة؛ لا توجد كلمة مرور افتراضية).

### متغيرات البيئة

| المتغير                        | مطلوب       | الوصف                                                                                                                                                                                                              |
| ------------------------------ | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `SUPABASE_URL`                 | نعم للإنتاج | رابط مشروع Supabase (بيانات الحسابات والاشتراكات فقط).                                                                                                                                                             |
| `SUPABASE_SERVICE_ROLE_KEY`    | نعم للإنتاج | مفتاح الخدمة الخاص بـ Supabase. سر مطلق ولا يوضع أبدًا في متغير يبدأ بـ `NEXT_PUBLIC_`.                                                                                                                             |
| `ADMIN_PASSWORD`               | نعم للإنتاج | كلمة مرور لوحة `/admin` (14 حرفًا على الأقل) وتُستخدم لتوقيع جلسة المسؤول.                                                                                                                                           |
| `SESSION_SECRET`               | نعم للإنتاج | سر مستقل لتوقيع جلسات المستخدمين وتوليد مفاتيح حدّ محاولات الدخول، ويستقل عن مفتاح Supabase. أنشئه بـ `openssl rand -base64 32`. تغييره يُسجّل جميع المستخدمين خروج (بياناتهم المحلية لا تُمس) ويُصفّر عدادات المحاولات. |
| `NEXT_PUBLIC_GOOGLE_CLIENT_ID` | اختياري     | Client ID عام من Google لتشغيل النسخ الاحتياطي المشفر على Drive. لا يوضع فيه أي Client Secret.                                                                                                                     |

### التطوير والفحوصات

- `npm run lint` — فحص ESLint (flat config، قواعد `next/core-web-vitals` و`next/typescript`) على `src/`.
- `npm test` — اختبارات وحدة Vitest داخل `tests/` تغطي حساب التواريخ المتكررة، تنبيهات الاستحقاق، تشفير نسخ Drive، التحقق من ملفات الاستعادة، وتوقيع الجلسات وكلمات المرور.
- `npm run format` / `npm run format:check` — تنسيق Prettier لملفات `src/`.
- ملف `.github/workflows/ci.yml` يشغّل الفحص السابق كله (تثبيت، lint، فحص أنواع، اختبارات، بناء) على كل pull request وعلى أي push إلى `main`.
- لإبلاغ عن ثغرة أمنية بشكل خاص راجع `SECURITY.md`.

## الاشتراك والدفع

يرسل العميل صورة التحويل إلى المسؤول عبر واتساب. بعد مراجعة الإيصال، يفعّل المسؤول الاشتراك مباشرة من لوحة `/admin` ويختار الباقة. لا يوجد كود تفعيل للعميل، ولا تُرسل صورة التحويل أو بيانات الدفع إلى قاعدة بيانات التطبيق. تبقى جلسة المسؤول على هذا الجهاز لمدة 7 أيام أو حتى تسجيل الخروج.

## حدود الاستضافة

سجلات العميل المالية لا تستهلك مساحة قاعدة Supabase؛ القاعدة تحفظ بيانات الحساب والاشتراك فقط. السعة الفعلية تتأثر بخطة Supabase وحدود Vercel وعدد مرات فتح التطبيق والتحقق من الاشتراك. راجع لوحة الاستخدام في الخدمتين بانتظام، ولا تستخدم خطة Vercel Hobby للبيع التجاري؛ راجع شروط Vercel والخطة المناسبة قبل استقبال اشتراكات مدفوعة.
