# تطبيق "على قدي" (Ala Qaddi) 💰
### تطبيق إدارة مالية شخصية محلي وخاص (Local-First PWA)

تطبيق مصمم خصيصاً للمستخدم العربي والمصري لإدارة المصاريف، الديون ("ليّا وعليّا")، الجمعيات الشهرية، ومدخرات الذهب والأصول بكل بساطة وهدوء، مع لوحة تحكم وتراخيص مخصصة للبيع المباشر.

---

## 🌟 أبرز المميزات:
1. **الخصوصية والعمل دون اتصال (Local-First)**: سجلات المعاملات والميزانيات والديون محفوظة محلياً على جهاز المستخدم (IndexedDB)، ويمكن استخدامها دون اتصال بعد تسجيل الدخول. إنشاء الحساب وتسجيل الدخول والتحقق من الاشتراك وإدارته تحتاج إلى الإنترنت.
2. **الاشتراكات ولوحة المسؤول (`/admin`)**: مراجعة الدفع وإدارته، تفعيل الاشتراك أو إيقاف الحساب، وتعديل بيانات التحويل الظاهرة للمستخدم.
3. **أقسام متكاملة**:
   - 🏠 **الرئيسية**: رصيد المحفظة، المتبقي من الراتب، شريط تقدم الميزانية الذكي.
   - 💳 **سجل المعاملات**: تصنيفات مصرية جاهزة (مصاريف بيت، بنزين، علاج، فواتير) وتصدير Excel (CSV).
   - 🤝 **قسم "ليّا وعليّا"**: سلف مستحقة عند الغير + ديون والتزامات مع سداد جزئي.
   - 🪙 **الجمعيات والذهب**: حساب الجمعيات الشهرية وموعد القبض، ومحفظة الذهب (عيار 21 و 24) والعملات.
   - 📊 **الميزانية والتقارير**: نسب المصروفات وطباعة تقرير شهري PDF.
   - ⚙️ **النسخ والاحتياطي**: حفظ نسخة مشفرة من البيانات ونقلها لأي جهاز آخر بسهولة.

---

## 🚀 التشغيل محلياً:

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# أو بناء الإنتاج والتشغيل
npm run build
npm start
```

- رابط التطبيق للمستخدمين: `http://localhost:3000`
- لوحة تحكم المسؤول: `http://localhost:3000/admin` (تحتاج إلى إعداد `ADMIN_PASSWORD` في متغيرات البيئة؛ لا توجد كلمة مرور افتراضية).

## الاشتراك والدفع

يرسل العميل إشعار التحويل عبر واتساب، ثم يراجع المسؤول الدفع ويعتمد الطلب من لوحة الإدارة. بعد الاعتماد، يُدخل العميل كود التفعيل الذي يرسله له المسؤول. لا تُرسل صورة التحويل أو بيانات الدفع إلى قاعدة بيانات التطبيق.

## حدود الاستضافة

سجلات العميل المالية لا تستهلك مساحة قاعدة Supabase؛ القاعدة تحفظ بيانات الحساب والاشتراك فقط. السعة الفعلية تتأثر بخطة Supabase وحدود Vercel وعدد مرات فتح التطبيق والتحقق من الاشتراك. راجع لوحة الاستخدام في الخدمتين بانتظام، ولا تستخدم خطة Vercel Hobby للبيع التجاري؛ راجع شروط Vercel والخطة المناسبة قبل استقبال اشتراكات مدفوعة.
