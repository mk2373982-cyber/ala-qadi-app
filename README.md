# تطبيق "على قدي" (Ala Qaddi) 💰
### تطبيق إدارة مالية شخصية محلي وخاص (Local-First PWA)

تطبيق مصمم خصيصاً للمستخدم العربي والمصري لإدارة المصاريف، الديون ("ليّا وعليّا")، الجمعيات الشهرية، ومدخرات الذهب والأصول بكل بساطة وهدوء، مع لوحة تحكم وتراخيص مخصصة للبيع المباشر.

---

## 🌟 أبرز المميزات:
1. **الخصوصية والعمل أوفلاين (Local-First)**: كافة البيانات المالية مخزنة محلياً على جهاز المستخدم (IndexedDB) وتعمل 100% بدون اتصال بالإنترنت.
2. **البيع المباشر ولوحة تحكم الأدمن (`/admin`)**: تفعيل فوري بضغطة زر (شهر، سنة، دائم)، إيقاف وطرد فوري للمستخدم، وتعديل بيانات استلام فودافون كاش وانستاباي.
3. **أقسام متكاملة**:
   - 🏠 **الرئيسية**: رصيد المحفظة، المتبقي من الراتب، شريط تقدم الميزانية الذكي.
   - 💳 **سجل المعاملات**: تصنيفات مصرية جاهزة (مصاريف بيت، بنزين، علاج، فواتير) وتصدير Excel (CSV).
   - 🤝 **قسم "ليّا وعليّا"**: سلف مستحقة عند الغير + ديون والتزامات مع سداد جزئي.
   - 🪙 **الجمعيات والذهب**: حساب الجمعيات الشهرية وموعد القبض، ومحفظة الذهب (عيار 21 و 24) والعملات.
   - 📊 **الميزانية والتقارير**: نسب المصروفات وطباعة تقرير شهري PDF.
   - ⚙️ **النسخ والاحتياطي**: حفظ نسخة مشفرة من البيانات ونقلها لأي جهاز آخر بسهولة.

---

## 🚀 التشغيل محلياً:

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# أو بناء الإنتاج والتشغيل
npm run build
npm start
```

- رابط التطبيق للمستخدمين: `http://localhost:3000`
- لوحة تحكم المسؤول: `http://localhost:3000/admin` (كلمة المرور الافتراضية: `admin`)
